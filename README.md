# Kitty Bow Pop

A kitty-face pop-it game for toddlers. Big bubbles, happy pop sounds, and a heart shower when every bubble is popped. The board then flips and starts over, so there is no losing, no timer and no score.

**Play:** https://saiftheboss7.github.io/hellokitty-popit-game/

## How it plays

- Tap a bubble to pop it, or slide a finger across a row to pop several. Multiple fingers work.
- The kitty's eyes and nose are bubbles too.
- After a few quiet seconds, one bubble bounces to invite the next tap.
- On a laptop, any key pops a random bubble.

## Grown-up buttons

Bottom right corner. Press and hold each one for about a second so little hands don't switch them by accident.

- Sound on or off
- Calm mode: quieter sounds and fewer sparkles
- Full screen
